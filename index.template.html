Your first pegboard

  1. Choose a style. SKÅDIS-style starts with 5 × 15 mm vertical slots, a 40 mm horizontal repeat, and staggered rows.
  2. Set width, height, thickness, and outline. A circle uses the same width and height.
  3. Set hole size and spacing. Border and grid offsets control where holes begin.
  4. Choose screw mounts. Set elongated-slot length, width, and angle for adjustment. Optional head seats and rear spacers remain editable.
  5. Check Hole layout. Amber marks show screw mounts. Empty positions preserve material near mounts and tile borders.
  6. Set Printer dimensions. Use Split to print an oversized board as individual tiles. Select a tile to inspect or download it; All tiles ZIP includes every tile and a placement guide.
  7. Download a fit test first. Check a hook and screw against your printer's actual result before printing the full board.
  8. Export STL or 3MF and open it in your slicer. Models face down on the bed; select filament and settings there. Save project keeps all dimensions editable.

SKÅDIS-style is an editable starting point. Changing slot width, thickness, or grid spacing can change accessory fit. Printed strength and fit depend on the material and print. This tool does not add connectors, slice G-code, or calculate load capacity.

Use Reset in the toolbar to restore default board and printer settings. You can undo a reset.
